## 🚀 Cómo empezar

### Paso 1 — Clona el repositorio
```bash
git clone [url-del-repositorio]
cd copilot-ejercicios
```

### Paso 2 — Abre en VS Code
```bash
code .
```

### Paso 3 — Verifica que Copilot está activo
Comprueba que el icono ✓ de Copilot aparece en la barra de estado inferior.

### Paso 4 — Crea el archivo de instrucciones
Crea `.github/copilot-instructions.md` con las convenciones de tu equipo
(el ejercicio 10 te guía cómo hacerlo).

## 💡 Atajos esenciales durante los ejercicios

| Acción | VS Code | Visual Studio 2022 |
|--------|---------|-------------------|
| Aceptar sugerencia | `Tab` | `Tab` |
| Rechazar sugerencia | `Esc` | `Esc` |
| Ver sugerencia siguiente | `Alt+]` | `Alt+.` |
| Ver 10 alternativas | `Ctrl+Enter` | — |
| Abrir chat | `Ctrl+Alt+I` | `View > GitHub Copilot Chat` |
| Chat inline (en editor) | `Ctrl+I` | `Alt+/` |

## 📖 Comandos del chat más usados en estos ejercicios

```
/explain  → Explica el código seleccionado
/fix      → Corrige errores o vulnerabilidades
/tests    → Genera tests unitarios
/doc      → Genera documentación XMLDoc/JSDoc
/simplify → Simplifica código complejo
/optimize → Mejora el rendimiento
```

## 📌 Consejos para sacar el máximo partido

1. **No copies y pegues directamente** — escribe los comentarios tú mismo para activar Copilot
2. **Itera sobre las respuestas** — si la sugerencia no es perfecta, pide variaciones
3. **Usa `Ctrl+Enter`** para comparar hasta 10 alternativas antes de elegir
4. **Comparte los prompts** que funcionan bien con el resto del equipo
5. **El ejercicio 10 es el más importante** — integra todo lo aprendido
